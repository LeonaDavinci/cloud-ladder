Preview: 

This is a relaxing, simple and short melody. I had a nostalgic feeling from this, so I put some production to enhance that effect. The long complete version cycles between a synth, a hurdy gurdy and a music box for the melody. There's also some simple repeating drums in the back ground coming and going. I think the styles shifts enough so it doesn't get completely repetative. 

I've also made short versions of the loop with each instrument used.
